# Resource hub

A wide catalogue of free and paid resources from across the community, beyond the course outlines in
`sources/`. Each line is `- [Title](url) · Type · Cost · Level · Note`. Type is one of Course, Video,
Book, Interactive, Practice, Repo, Article, Blog, Newsletter, Podcast, Paper, Docs or Tool. Cost is
Free, Freemium or Paid. Level is Beginner, Intermediate or Advanced. The site turns this file into
the searchable Resources tab, so keep the format when you add entries.

Some entries come from two community lists worth browsing in full:
[awesome-engineering](https://github.com/briancorbinxyz/awesome-engineering) and
[awesome-engineering-ai](https://github.com/Lancetnik/awesome-engineering-ai).
