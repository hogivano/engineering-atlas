# Claims to spot-check

Lesson writers flagged numbers and defaults they stated from memory. Every one was then checked
against a primary or authoritative source (official docs, source code, papers, vendor engineering
blogs) on 2026-10-16:

- **Verified**: the source states it.
- **Corrected**: the source said something different; the lesson was fixed (see the note).
- **Unverified**: no authoritative source exists (usually hardware-dependent benchmark figures);
  the lesson words these as approximate. Measure on your own hardware before relying on them.
- **Assumption**: a planning number the lesson labels as an assumption.

Each lesson page shows its unverified claims under "Numbers to double-check". To help, verify an
Unverified row, fix the lesson if needed, and change the status with a link to the source.

**Summary:** 4 corrected, 15 unverified, 3 assumption, 140 verified.
